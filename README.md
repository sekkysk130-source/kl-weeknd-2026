# KL × The Weeknd 🎤 (3–5 พ.ย. 2026)

เว็บแอปส่วนตัวสำหรับทริป Kuala Lumpur 3 คน · โครงเดียวกับ `personal/sg-f1-2026` (เว็บนิ่ง ไม่มี build ไม่มี API key)

## รัน

```bash
cd personal/kl-weeknd-2026 && python3 -m http.server 8765
```

เปิด http://localhost:8765 · ทดลองเวลาได้ด้วย `?sim=2026-11-04T17:00` (เวลามาเลเซีย)

> โฟลเดอร์นี้อยู่ใน iCloud ถ้า python เปิดไม่ได้ (Operation not permitted) ให้ copy ไปไว้นอก iCloud ก่อน:
> `rsync -a --delete --exclude tests ./ ~/.kl-weeknd-preview/` แล้วรันในโฟลเดอร์นั้น

## เทสสูตรคำนวณ

```bash
node --test tests/
```

ครอบ: ราคาต่อคน/ต่อคัน, ราคาที่กรอกเอง, จัดอันดับวิธีเดินทาง, เวลาออกไปคอนเสิร์ต/สนามบิน, สรุปเงิน + แปลงบาท, ใครโอนให้ใคร, validation

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `data.js` | **ข้อมูลทริปทั้งหมด** — เที่ยวบิน แพลน 3 วัน ช่วงทาง+ราคา แหล่งอ้างอิง เช็กลิสต์ ไอเดียที่เที่ยว |
| `logic.js` | สูตรคำนวณล้วน (ใช้ทั้งเว็บและเทส) |
| `app.js` | หน้าจอ 6 หน้า + เก็บสิ่งที่แก้ใน localStorage |
| `sw.js` | เก็บแอปไว้ใช้ตอนไม่มีเน็ต |

หลังแก้ `data.js` ให้เปลี่ยน `BUILD` ใน `data.js` และ `V` ใน `sw.js` ไม่งั้นมือถือจะยังเห็นฉบับเก่า

## สถานะข้อมูล

ทุกตัวเลขมีป้าย: **ยืนยันแล้ว** / **ประมาณการ** / **รอตรวจสอบ** / **ข้อมูลของเรา** / **ต้องกรอก** + ลิงก์แหล่งที่มา
ราคาที่หาแหล่งไม่ได้ (Grab ในเมือง) = "ยังไม่มีราคา" ไม่ใส่ 0 และไม่ถูกแนะนำในโหมดประหยัด

## API

ไม่มีการดึงข้อมูลสด — ตั้งใจ เพราะเว็บนิ่งบน GitHub Pages เก็บ API key ไม่ได้ และทริปใกล้แล้ว
"Open in Maps" ใช้ลิงก์ธรรมดาของ Google Maps / Apple Maps / Waze (เลือกในตั้งค่า) ไม่ต้องใช้ key
ถ้าจะต่อ API ในอนาคต (Google Directions, อัตราแลกเปลี่ยน) ต้องมี backend เล็ก ๆ ถือ key ไว้ ห้ามใส่ key ใน `data.js`

## แผนที่ใช้ (ฉบับ 2 · 30 ต.ค.)

แผนเสนอชุดที่ 2 + ปรับ: ตัด Batu Caves (ย้ายไปไอเดีย) · KLCC ย้ายไป 5 พ.ย. · เพิ่มมื้อเที่ยงวันแรก · บัตรนั่ง → กินข้าวเย็นแล้วออก 17:13 ถึงสนาม 18:30 · Grab ขาเข้า / LRT ไปสนาม / KLIA Ekspres ขากลับ (ออก 14:52 ถึง T2 16:00) · จุดรับ Grab หลังงาน = Endah Parade (ผู้จัด) · งบตั้งต้น RM533 ตามแผน

## ต้องตรวจก่อนเดินทาง (ตรงกับเช็กลิสต์ในแอป)

1. กรอก MDAC ทั้ง 3 คน (31 ต.ค.–3 พ.ย.)
2. เช็กอินออนไลน์ AirAsia AK891 / AK896
3. ประตูเข้าตามตั๋ว + ของต้องห้าม (พาวเวอร์แบงก์ ≤10,000 mAh, กระเป๋า ≤A4, ห้ามร่ม)
4. รถไฟขากลับหลังคอนเสิร์ต — ยังไม่มีประกาศขยายเวลา ณ 30 ต.ค.
5. จำนวน/ขนาดกระเป๋า (เลือกขนาด Grab)
6. NU Hotel ฝากกระเป๋าหลังเช็กเอาต์
7. เติม Touch 'n Go + พกบัตรเครดิต (ที่ฝากของ/ของที่ระลึกรับแต่บัตร)
8. เรทแลกเงินจริง (แอป 8.20 / แผน 8.33)

ไม่ใส่รหัสจองตั๋วในแอป เพราะเว็บเปิดได้จากลิงก์
